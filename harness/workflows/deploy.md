# deploy - 部署到 AWS

> 历史文档：以下 EC2 Web/PostgreSQL 部署流程及脚本已废弃，不应按本文执行。当前入口见 [部署说明](../../scripts/deploy/README.md)；Go API 生产认证未完成，生产部署保持暂停。

## 任务

部署 Web 应用到 AWS EC2，使用 GitHub Actions 构建镜像并推送到 ECR。

## 最小上下文

- `scripts/deploy/docker-compose.yml` - 容器配置
- `scripts/deploy/Dockerfile.web` - 镜像定义
- `.github/workflows/build-and-push-ecr.yml` - 自动构建流程
- `.env.example` - 环境变量模板

## 前置条件

一次性配置（首次部署）：

1. **AWS IAM 角色**：创建信任 GitHub OIDC 的角色，附加 ECR 权限
2. **AWS ECR 仓库**：创建 `greenfield-web` 公共仓库
3. **GitHub Secret**：添加 `AWS_ROLE_TO_ASSUME` (IAM 角色 ARN)

## 工作流

### 步骤 1：推送代码触发构建

```bash
git push origin main
```

GitHub Actions 自动：
- 构建 Docker 镜像
- 推送到 AWS ECR
- 标记：`latest`、Git SHA、分支名

### 步骤 2：在 EC2 上部署

```bash
# SSH 连接
ssh ubuntu@16.170.155.138

# 首次：克隆项目
git clone <repo-url> ~/greenfield-adventures
cd ~/greenfield-adventures

# 部署
chmod +x scripts/deploy/deploy-simple.sh
./scripts/deploy/deploy-simple.sh
```

脚本自动：
- 安装 Docker/Docker Compose（如需要）
- 生成 `.env` 文件和强密码
- 登录 ECR
- 启动容器

### 步骤 3：验证

访问 `http://EC2_IP:3000`

## 环境变量

`.env` 文件（EC2 上，由 deploy-simple.sh 生成）：

```env
DB_NAME=greenfield_adventures
DB_USER=postgres
DB_PASSWORD=<auto-generated-32-chars>
DB_PORT=5432
WEB_PORT=3000
WRITER_AGENT_MODE=demo
NODE_ENV=production
```

## 常用命令

```bash
# 查看状态
docker-compose -f scripts/deploy/docker-compose.yml ps

# 查看日志
docker-compose -f scripts/deploy/docker-compose.yml logs -f

# 重启
docker-compose -f scripts/deploy/docker-compose.yml restart
```

## 故障排除

| 问题 | 检查 | 解决 |
|------|------|------|
| Actions 构建失败 | GitHub Actions 日志 | 检查 IAM 权限、ECR 仓库 |
| 镜像拉取失败 | ECR 登录 | `aws ecr-public get-login-password` |
| 容器无法启动 | `docker-compose logs` | 检查端口占用、环境变量 |

## 安全约束

- ❌ 不提交 `.env` 文件到 Git（已在 `.gitignore`）
- ❌ 不在代码中硬编码密钥
- ✅ 使用 IAM 角色 + OIDC（无长期凭证）
- ✅ 数据库密码 ≥ 32 字符
- ✅ `.env` 文件权限 600

## 输出

- Web 应用运行在 `http://EC2_IP:3000`
- PostgreSQL 运行在 `localhost:5432`
- 数据持久化在 Docker 卷 `postgres_data`
