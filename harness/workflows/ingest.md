# 写后同步
输入：作者指定的正文文件。
1. 读目标正文，记录路径和内容 hash；查询既有章节提取，hash 相同则复用，避免重复。
2. 提取事件、角色变化、知识边界、时间地点、设定与伏笔；每项给段落证据并区分事实/叙述/推断。
3. 可直接写 notes/ 章节摘要与影响清单，不直接提升为 confirmed。
4. 新事实和冲突逐条写 proposals/，列出涉及的 characters、threads、world、timeline、outline 路径。
5. 更新 current 和相关索引中的“待确认”状态。正文不变。
完成标准：每项候选有证据；没有无依据补写；重复运行不新增相同提案。
