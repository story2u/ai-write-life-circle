# 部署配置文件

此目录包含 AWS 部署所需的配置文件。

## 文件说明

| 文件 | 用途 |
|------|------|
| `deploy-simple.sh` | EC2 部署脚本（推荐使用） |
| `docker-compose.yml` | 容器编排配置 |
| `Dockerfile.web` | Web 应用镜像定义 |
| `deploy-ec2.sh` | 完整部署脚本（备用） |
| `upload-to-ec2.sh` | 文件上传工具（备用） |

## 使用方法

参考根目录 [DEPLOY.md](../DEPLOY.md) 或详细工作流 [harness/workflows/deploy.md](../harness/workflows/deploy.md)

## 配置

环境变量在 EC2 的 `.env` 文件中（由 `deploy-simple.sh` 生成）：

```env
DB_NAME=greenfield_adventures
DB_USER=postgres
DB_PASSWORD=<auto-generated>
DB_PORT=5432
WEB_PORT=3000
WRITER_AGENT_MODE=demo
NODE_ENV=production
```

不要提交 `.env` 文件到 Git。
