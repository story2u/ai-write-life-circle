## Sprint 1 work implemented

- Read-only Harness Markdown reader for allowlisted repository directories,
  with SHA-256/Git blob hashes and symlink skipping.
- Parser for the repository's leading key-value metadata; it preserves raw
  Markdown, values, and unknown statuses without inferring canon or clause
  state.
- Path-addressed projections for knowledge, proposals, chapter candidates, and
  ID collisions; duplicate IDs are retained instead of arbitrarily collapsed.
- File-backed ID reservation primitive in caller-provided application state;
  it blocks conflicting `WORLD`/`P` prefixes and the singleton `INTENT`
  prefix, and can reserve `CH` IDs under the existing stable-ID rule. It never
  writes a Harness record.
- Append-only audit-log primitive and a generic 409 revision compare-and-swap
  guard.
- Local Fetch-compatible API: health check, diagnostic Harness projection,
  Workspace GET/PATCH, Chapter list/detail/revision history, and author-only
  immutable application draft saves. Saves enforce base-revision CAS,
  idempotency keys, duplicate-ID rejection, and external-source conflict
  checks. Drafts and workspace state are stored outside the Harness; no Git
  writes or commit refs are produced.
- `packages/contracts/src/v04.ts` defines the Zod runtime schemas and inferred
  TypeScript types for the implemented Workspace/Chapter subset. The complete
  author-supplied OpenAPI source is now versioned; a generated candidate adds
  operation status and the lossless Markdown/audit fields. Redocly validates
  OpenAPI 3.1 syntax and API tests compare the implemented subset to Zod. Types
  are not code-generated from OpenAPI.
- Chapter API stores and returns exact Markdown strings. The TipTap round-trip
  test covers Chinese paragraphs, blank lines, block quotes, lists, hard
  breaks, and special characters. Syntax not supported by the current editor
  (tables, images, task lists, footnotes, reference links, and raw HTML) stays
  read-only as raw Markdown so an edit cannot silently flatten it.
- Save audit attempts and terminal outcomes share the request/correlation ID;
  tests distinguish created, idempotent replay, validation, permission,
  conflict, and storage failure. A failed write has no `saved` event.
- Existing CI scripts now include API typecheck/build/tests through root
  package scripts.

The storage, allocator, audit and compare-and-swap foundations are primitives;
they are not wired into a persistent chapter workflow. See
`docs/architecture/adr/ADR-0001-sprint1-harness-projection.md`.
